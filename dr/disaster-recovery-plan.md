# План аварийного восстановления

1. Установить Ubuntu Server
2. Установить необходимые пакеты: nginx, mysql, php
3. Склонировать GitHub-репозиторий проекта
4. Разложить конфиги:
   - nginx
   - mysql (master/slave)
   - php
5. Настроить MySQL master-slave
6. Восстановить БД из бэкапа со slave
7. Проверить работу сайта через балансировщик
8. Убедиться, что мониторинг Netdata работает
